# Agent 2 — Symmetry & Reduction

**Scope.** Discrete symmetry group of the 2+/2− 4-body Weber Hamiltonian, dimension reduction count, Jacobi coordinates adapted to the (++)(−−) splitting, and invariant submanifolds usable by Agent 5 for periodic-orbit shooting.

**Working assumptions.** All masses equal `m₁=m₂=m₃=m₄=m`, charges `q₁=q₂=+q`, `q₃=q₄=−q`, all `κ_ij=1` (Zöllner off). The Weber Hamiltonian is

```
H = Σ_i p_i·p_i / (2 m_i) + Σ_{i<j} (q_i q_j / r_ij) (1 − ṙ_ij²/(2c²))
```
with the convention `ṙ_ij = p/m`-substituted, exactly as in `theory/WeberElectrodynamics.md`.

## 1. Discrete symmetry group

Layout: `q = [x_1,y_1,…,x_4,y_4]`, `p` analogously. A discrete symmetry is encoded as `(σ, ε_q, ε_p)` where `σ∈S_4` permutes particle labels and `ε_q,ε_p ∈ {±1}` flip positions / momenta jointly.

| Generator | Action on (q,p) | Why a symmetry |
|-----------|-----------------|----------------|
| `S₁₂` | swap labels 1↔2 | particles 1,2 identical (m,q) |
| `S₃₄` | swap labels 3↔4 | particles 3,4 identical (m,−q) |
| `C` (charge conjugation) | swap 1↔3, 2↔4 | q→−q under this swap, but H depends only on `q_iq_j` → invariant. Pair (1↔3) flips sign of one charge in every pair product; pair (2↔4) flips the other. Symmetric. |
| `P` (parity) | `q→−q, p→−p` | even in both q and p; r_ij and ṙ_ij invariant |
| `T` (time reversal) | `p→−p` | H is even in p (kinetic and ṙ²) |
| `R(θ)` | rotate every (x_i,y_i) by θ | continuous SO(2) — handled by reduction below |

Because `P` is the composition of an internal sign flip and `T·(P̂_q)` is independent, the discrete group is a direct product:

```
G = ⟨S₁₂⟩ × ⟨S₃₄⟩ × ⟨C⟩ × ⟨P⟩ × ⟨T⟩  ≅ (Z₂)⁵,   |G| = 32.
```

Strictly speaking `C` is not independent of `S₁₂,S₃₄` *as a permutation*, because it permutes 1↔3 and 2↔4; but in the equal-mass equal-|q| 2+/2− case, that permutation happens to also be an isometry of H — that is the content of "C is a symmetry". So G is the subgroup of `S_4 × Z₂(P) × Z₂(T)` generated by `{S₁₂, S₃₄, C, P, T}`. The permutation part is `⟨S₁₂,S₃₄,C⟩ = ⟨(12),(34),(13)(24)⟩ = D_4` of order 8, the dihedral group of the square (1,2,3,4). So an equivalent description is

```
G  =  D_4(particle labels)  ×  Z_2(P)  ×  Z_2(T)        with  |G| = 8·2·2 = 32.
```

A few elements deserve explicit names because Agent 5/Agent 11 will use them:

| Name | Element | Action |
|------|---------|--------|
| `Σ_intra` | `S₁₂·S₃₄` | swap within each species |
| `CP` | `C·P` | full +↔− with spatial inversion |
| `CT` | `C·T` | full +↔− with time reversal |
| `Σ_intra·T` | half-period symmetry of "breathing dimer" orbits | |

### Numerical verification

The script `verify_symmetries.jl` evaluates the compiled Hamiltonian on 20 random configurations for every generator and checks `|H(τ·q,τ·p) − H(q,p)| / |H| < 10⁻¹⁰`. Result:

```
S12, S34, S12*S34, P, T, PT, C, CP, CT, CPT     all OK at ≤ 5e-16
S13 (negative control)                          FAIL  (rel err ≈ 1.7)
```

Since H is rational in (q,p) the equality at random rational points is a definitive proof, not just a numerical coincidence.

## 2. Continuous symmetries and conserved quantities

| Group | DOF removed | Conserved | Notes |
|-------|------------:|-----------|-------|
| Translation `R^d` | d | total `P_tot = Σ p_i` | reduce by passing to COM frame |
| Rotation `SO(d)` | d(d−1)/2 | total `L = Σ x_i ∧ p_i` | reduce by passing to a body frame |
| Time translation | (level set) | `H = E` | one constraint, no quotient |

The Weber S in the Lagrangian is invariant under these because every `r_ij` and every `ṙ_ij` is. Boost invariance is **broken** — Weber theory is Galilean only in the COM frame.

## 3. Reduction count

Phase space dimension `2·d·N` for N=4:

| Step | 2D | 3D |
|------|----|----|
| Full phase space | 16 | 24 |
| Fix COM position (−d) | 14 | 21 |
| Fix total momentum (−d) | 12 | 18 |
| Fix energy (−1) | 11 | 17 |
| Quotient by SO(d) (−dim SO(d), then drop conjugate) | 11−2=9 | 17−4=13 |

For 2D the SO(2) reduction removes one angle and fixes L, dropping 2 net dimensions → **reduced energy surface dim = 9**. This is large enough to host invariant tori (KAM) and chaotic web (Agent 6); too large for direct Poincaré-section visualization without further symmetry constraints (Agent 5 will exploit the Z₂ subgroups below).

For 3D: 17→13. The full reduced symmetry group still acts faithfully and can be modded out for finer dimension counts, but quotienting by a discrete group does not reduce dimension.

## 4. Jacobi coordinates adapted to (++)(−−)

Define the following four `d`-vectors:

```
r₊  = x₂ − x₁                                 (intra-positive separation)
r₋  = x₄ − x₃                                 (intra-negative separation)
R   = (x₃+x₄)/2 − (x₁+x₂)/2                  (inter-dimer vector)
R_c = (x₁+x₂+x₃+x₄)/4                         (COM, to be discarded)
```

Inverse (equal masses):
```
x₁ = R_c − R/2 − r₊/2,   x₂ = R_c − R/2 + r₊/2,
x₃ = R_c + R/2 − r₋/2,   x₄ = R_c + R/2 + r₋/2.
```

The standard Jacobi reduced masses:
```
μ₊ = m/2,   μ₋ = m/2,   μ_R = (2m·2m)/(2m+2m) = m.
```

Conjugate momenta (from a generating-function or direct linear algebra check):
```
P₊  = (p₂ − p₁)/2,        ṙ₊ = P₊/μ₊  = 2P₊/m
P₋  = (p₄ − p₃)/2,        ṙ₋ = P₋/μ₋  = 2P₋/m
P   = (p₃+p₄)/2 − (p₁+p₂)/2,  Ṙ = P/μ_R = P/m
P_c = p₁+p₂+p₃+p₄                              (= 0 in COM frame)
```

Kinetic energy after the linear canonical transformation:
```
T = P_c²/(2·4m) + P²/(2 μ_R) + P₊²/(2 μ₊) + P₋²/(2 μ₋)
  = P_c²/(8m)    + P²/(2m)    + P₊²/m       + P₋²/m
```

The intra-species swap acts very simply:
```
S₁₂ : r₊ → −r₊,  P₊ → −P₊,  others fixed.
S₃₄ : r₋ → −r₋,  P₋ → −P₋,  others fixed.
```
Charge conjugation `C` (1↔3, 2↔4) acts as
```
C : r₊ ↔ r₋,   P₊ ↔ P₋,   R → −R,   P → −P.
```
Parity `P_total : q→−q` flips all four Jacobi vectors. Time reversal flips all four momenta. So the entire discrete `(Z₂)^k` action descends to sign flips and a swap on the three reduced relative vectors `(r₊, r₋, R)` — extremely clean.

## 5. Pairwise relative velocities in Jacobi coordinates

The six pairs and their relative position vectors:

```
r₁₂ = r₊                                   (length r₊)
r₃₄ = r₋                                   (length r₋)
r₁₃ = R + (r₋ − r₊)/2          (uses both dimers)
r₁₄ = R + (r₋ + r₊)/2
r₂₃ = R − (r₊ + r₋)/2
r₂₄ = R + (r₋ − r₊)/2 + r₊  =  R + (r₋ + r₊)/2 + ?  
```
Re-derive systematically: with `x₁ = −R/2 − r₊/2`, `x₂ = −R/2 + r₊/2`, `x₃ = R/2 − r₋/2`, `x₄ = R/2 + r₋/2` (COM removed):
```
r₁₂ = x₂−x₁ = r₊
r₃₄ = x₄−x₃ = r₋
r₁₃ = x₃−x₁ = R − r₋/2 + r₊/2     (≡ R + (r₊−r₋)/2)
r₁₄ = x₄−x₁ = R + r₋/2 + r₊/2     (≡ R + (r₊+r₋)/2)
r₂₃ = x₃−x₂ = R − r₋/2 − r₊/2     (≡ R − (r₊+r₋)/2)
r₂₄ = x₄−x₂ = R + r₋/2 − r₊/2     (≡ R − (r₊−r₋)/2)
```
Time-derivatives use the same linear combinations of `(ṙ₊, ṙ₋, Ṙ) = (2P₊/m, 2P₋/m, P/m)`:
```
ṙ₁₂ = 2P₊/m
ṙ₃₄ = 2P₋/m
ṙ₁₃ = P/m + (P₊−P₋)/m
ṙ₁₄ = P/m + (P₊+P₋)/m
ṙ₂₃ = P/m − (P₊+P₋)/m
ṙ₂₄ = P/m − (P₊−P₋)/m
```
The radial (scalar) relative speeds `ṙ_ij = (r_ij·ṙ_ij)/|r_ij|` then follow by direct substitution. These six expressions are what gets plugged into the Weber correction `(1 − ṙ_ij²/(2c²))`. The full reduced Hamiltonian appears in `reduced_hamiltonian.md`.

## 6. Symmetry-adapted invariant submanifolds

Each generator has a fixed-point set; restricting the dynamics to such a set gives an invariant submanifold (Hamilton's equations preserve the symmetry). The candidates Agent 5 should target:

| Subgroup `H` | Fix(H) in (r₊,r₋,R,P₊,P₋,P) | Reduced dim (2D, COM removed) | Use |
|--------------|------------------------------|---:|-----|
| `S₁₂·S₃₄` (intra-swap) | r₊=0, r₋=0, P₊=0, P₋=0 — collapsed to a single 2-body relative problem. **Too restrictive.** Use the variant: trajectories on which `r₊∥r₋` and `P₊∥P₋` (Fix of the Z₂ that flips both) | 8 (from 12) | "rectangle" family |
| `Σ_intra·T` ⟨combined⟩ | configurations where exchanging the two (+) and the two (−) and reversing time is trivial — i.e. half-period reflection symmetry. Forces `P₊=−P₊→0` and `P₋=−P₋→0` at the symmetric instant. | 6 | half-period boundary condition for shooting |
| `C` (1↔3,2↔4) | r₊ = r₋ (call it `s`), P₊=P₋, **R=0**, P=0 — equal-shape, dimer-coincident configurations. | 4 | "isosceles" / square family |
| `CP` | r₊ = −r₋, P₊ = −P₋, R, P arbitrary | 8 | "antisymmetric dimer-pair" |
| `T` alone | P=0, P₊=0, P₋=0 (all momenta vanish at the symmetric instant) | 6 | classical "brake orbit" boundary condition — Agent 5 will use this for symmetric periodic orbit shooting |
| Reflection across x-axis (D₂ spatial subgroup that preserves the 2+/2− labelling, e.g. y_i → −y_i) | configurations with all y_i = 0 → **collinear sub-problem** | 4 | linear ABAB / AABB chain — already partially studied in research/Investigations |

The two *most* useful for periodic-orbit shooting (Agent 5):
1. **`T`-fixed (brake) submanifold.** Search a periodic orbit by integrating from a configuration with `P=P₊=P₋=0`, looking for a later instant where the same condition recurs (after possibly applying `C` or `Σ_intra`); the orbit then closes by symmetry. Reduces a 2-point boundary search to a 1-sided shooting problem.
2. **`C`-fixed (square-symmetric) submanifold.** A 4D symplectic submanifold; periodic orbits here are guaranteed for a parameterized family by Lyapunov center theorem near the relative equilibrium. Cf. Agent 4.

The collinear submanifold is fully decoupled from transverse modes only on its fixed set; transverse Floquet multipliers there will determine the transverse stability already noted in `research/Investigations/FourPositiveChargeCrossInvestigation.md`.

## Key takeaways for downstream agents

- Discrete symmetry group `G ≅ D₄ × Z₂ × Z₂`, order 32.
- Reduced energy surface in 2D is 9-dimensional; in 3D, 13-dimensional.
- Jacobi coordinates `(r₊,r₋,R)` make the discrete action diagonal: at most a sign flip plus the swap `r₊↔r₋`.
- Six concrete symmetry-restricted submanifolds are available; the **brake-orbit** (`T`-fixed) and **square-symmetric** (`C`-fixed) submanifolds are the natural targets for Agent 5's shooting routines.

## Reduced Hamiltonian

# Reduced Hamiltonian — 4-body 2+/2− Weber in Jacobi coordinates

Equal masses `m₁=m₂=m₃=m₄=m`, charges `q₁=q₂=+q`, `q₃=q₄=−q`, all `κ_ij=1`.

## Coordinates

```
r₊  = x₂ − x₁                       (intra-positive,  μ₊ = m/2)
r₋  = x₄ − x₃                       (intra-negative,  μ₋ = m/2)
R   = (x₃+x₄)/2 − (x₁+x₂)/2         (inter-dimer,    μ_R = m)
R_c = (x₁+x₂+x₃+x₄)/4               (COM, removed)
```

Conjugate momenta:
```
P₊  = (p₂ − p₁)/2
P₋  = (p₄ − p₃)/2
P   = (p₃+p₄)/2 − (p₁+p₂)/2
P_c = p₁+p₂+p₃+p₄  ≡ 0  (COM frame)
```

Inverse (in the COM frame, R_c=0, P_c=0):
```
x₁ = −R/2 − r₊/2,    p₁ = −P/2 − P₊
x₂ = −R/2 + r₊/2,    p₂ = −P/2 + P₊
x₃ = +R/2 − r₋/2,    p₃ = +P/2 − P₋
x₄ = +R/2 + r₋/2,    p₄ = +P/2 + P₋
```

(Check Σpᵢ = 0 ✓ ; one verifies `{r_α, P_β} = δ_{αβ}` for α,β ∈ {+,−,R}.)

## Pair separations

```
r₁₂ = r₊
r₃₄ = r₋
r₁₃ = R + (r₊ − r₋)/2
r₁₄ = R + (r₊ + r₋)/2
r₂₃ = R − (r₊ + r₋)/2
r₂₄ = R − (r₊ − r₋)/2
```
with magnitudes `r_ij = |r_ij|` (Euclidean norm in `d` dimensions).

## Pairwise relative velocities

In the equal-mass case, `ẋ_i = p_i/m`, so `ẋ_j − ẋ_i = (p_j − p_i)/m`. Substituting:

```
ṙ₁₂ = 2 P₊ / m
ṙ₃₄ = 2 P₋ / m
ṙ₁₃ = (P + P₊ − P₋) / m
ṙ₁₄ = (P + P₊ + P₋) / m
ṙ₂₃ = (P − P₊ − P₋) / m
ṙ₂₄ = (P − P₊ + P₋) / m
```
(These are vector relative velocities. The scalar Weber `ṙ_ij = (r_ij · ṙ_ij)/|r_ij|`.)

## Kinetic term

```
T = P²/(2m) + P₊²/m + P₋²/m
```
(Using μ_R = m, μ₊ = μ₋ = m/2.)

## Potential — Coulomb limit (c → ∞)

```
U_Coul = +q²/r₁₂ + q²/r₃₄                  (like-pairs, repulsive)
       − q²/r₁₃ − q²/r₁₄ − q²/r₂₃ − q²/r₂₄  (unlike pairs, attractive)
```
Substitute the Jacobi pair expressions:

```
U_Coul(r₊,r₋,R) =
   q² [ 1/|r₊| + 1/|r₋|
        − 1/|R + (r₊−r₋)/2|
        − 1/|R + (r₊+r₋)/2|
        − 1/|R − (r₊+r₋)/2|
        − 1/|R − (r₊−r₋)/2| ]
```

The full Coulomb-limit reduced Hamiltonian:
```
H_Coul = P²/(2m) + P₊²/m + P₋²/m + U_Coul(r₊, r₋, R).
```
This Hamiltonian is invariant under (i) `r₊ → −r₊`, (ii) `r₋ → −r₋`, (iii) `r₊ ↔ r₋, R → −R`, (iv) parity, (v) time reversal — exactly the discrete group enumerated in `NOTES.md`.

## Weber correction (full reduced H)

Each Coulomb pair gets multiplied by `(1 − ṙ_ij²/(2c²))`:
```
H_Weber = T + Σ_{i<j} (q_i q_j / r_ij) · (1 − ṙ_ij² / (2c²))
```
where `q_iq_j` is `+q²` for (12),(34) and `−q²` for the four cross pairs, the `r_ij` are the Jacobi expressions above, and `ṙ_ij` is the scalar radial speed:
```
ṙ_ij = (r_ij · ṙ_ij^{vec}) / r_ij
```
with the six `ṙ^{vec}` already listed above.

Schematically:
```
H_Weber = P²/(2m) + P₊²/m + P₋²/m
        + q² [ (1/r₁₂)(1 − (2P₊/m)·r̂₁₂)²/(2c²)
              + (1/r₃₄)(1 − (2P₋/m)·r̂₃₄)²/(2c²)  ]
        − q² Σ_{cross} (1/r_ij)(1 − (ṙ_ij)²/(2c²)).
```
Expanding fully would produce a long expression with `O(20)` rational+square-root terms — the symbolic version is available directly from `HamiltonianSystem(4,2).hamiltonian_symbolic` and a follow-up Jacobi substitution; the algebraic simplification was found to be expensive (Symbolics `simplify` did not converge in 15 min on this input). For analytic work it is most useful to keep `H_Weber` in the schematic form above and substitute Jacobi expressions only in the specific submanifold being studied.

## Symmetry-restricted simplifications

### Square-symmetric subspace (`C`-fixed: r₊ = r₋ ≡ s, P₊ = P₋ ≡ Π, R = 0, P = 0)

In this 4D submanifold the four cross pairs collapse to two pair lengths and the kinetic part collapses too:
```
r₁₂ = r₃₄ = s
r₁₃ = r₂₄ = (r₊ − r₋)/2 = 0    (when r₊ = r₋)
r₁₄ = r₂₃ = r₊ = s
```
Wait — when R=0 and r₊=r₋=s, the cross pairs degenerate (r₁₃=0). This is the **collinear coincidence** singularity, not a regular submanifold. The proper "square" relative equilibrium uses **r₊ ⟂ r₋** with equal magnitudes, not r₊ = r₋ as vectors. Let `r₊ = s ê_x`, `r₋ = s ê_y`, `R = 0`. Then:
```
r₁₂ = s, r₃₄ = s,
r₁₃ = (s ê_x − s ê_y)/2  →  |r₁₃| = s/√2
r₁₄ = (s ê_x + s ê_y)/2  →  |r₁₄| = s/√2
r₂₃ = (−s ê_x − s ê_y)/2 →  |r₂₃| = s/√2
r₂₄ = (−s ê_x + s ê_y)/2 →  |r₂₄| = s/√2
```
This is the alternating square. Coulomb potential:
```
U_□(s) = 2·(q²/s) − 4·(q²/(s/√2)) = q²/s · (2 − 4√2).
```
Negative ⇒ bound; the symmetric square is a Coulomb relative equilibrium with rotation rate ω determined by `2 m ω² s² = −s · dU/ds` — Agent 4 will compute the Weber correction.

### Brake submanifold (`T`-fixed: P = P₊ = P₋ = 0)

```
H|_T = U_Coul(r₊, r₋, R)        (and the Weber correction vanishes because every ṙ_ij = 0)
```
Hence on the brake submanifold the Weber problem coincides with the Coulomb problem. This is a **rigorous** simplification, and means brake-orbit boundary conditions for periodic orbits can be searched using only the Coulomb potential — the Weber correction enters only off the brake.

### Two-dimer asymptotic (|R| ≫ |r₊|, |r₋|)

Multipole-expand the four cross potentials in (r₊, r₋)/R. To leading order the (+−) dipole moments d₊ = q r₊, d₋ = q r₋ (or rather the centers-of-charge difference) couple as a dipole-dipole term ~ (d₊·d₋ − 3(d₊·R̂)(d₋·R̂)) / R³. This is the regime where the "dimer-dimer orbital" candidate orbits (Agent 5) live. The internal dimer dynamics are 2-body Coulomb (Kepler) plus Weber, giving rise to the standard precessing ellipses studied in `examples/two_body_reference.ipynb`.
