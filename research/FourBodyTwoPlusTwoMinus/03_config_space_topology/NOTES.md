# Configuration-Space Topology of the 2+/2− 4-body Weber Problem

Agent 3 deliverable. Purely topological, no numerics.
Statements are tagged **[thm]** (cited theorem) or **[conj]** (this report).

## 1. Setup

Let `N = 4`, charges `(q1, q2, q3, q4) = (+,+,−,−)`, ambient dimension `d ∈ {2,3}`.
Translation-reduced configuration space:
```
X_N(R^d) := (R^d)^N / R^d,    dim = d(N−1) = 3d.
```
The collision diagonal is `Δ = {x : ∃ i<j, x_i = x_j}`. The Coulomb-regular
configuration space is the **ordered configuration space**
```
F(R^d, N) = (R^d)^N \ Δ        (Fadell–Neuwirth).
```
We work with `F(R^d, 4)` (or its translation quotient — the homotopy type is the
same up to a contractible R^d factor) throughout.

## 2. Fadell–Neuwirth and the Coulomb baseline

**[thm]** (Fadell–Neuwirth 1962). The forgetful map
```
F(R^d \ {n−1 pts}, 1) ↪ F(R^d, n) ↠ F(R^d, n−1)
```
is a locally trivial fibration. Iterating from `n = 4` down to `n = 1` decomposes
`F(R^d, 4)` as a tower of fibrations whose fibers are punctured Euclidean spaces.

### d = 2

**[thm]** (Arnold 1969). `F(R^2, n)` is a `K(P_n, 1)` for the pure braid group
`P_n`, with Poincaré polynomial
```
P_{F(R^2, n)}(t) = ∏_{k=1}^{n−1} (1 + k t).
```
For `n = 4`:
```
P(t) = (1+t)(1+2t)(1+3t) = 1 + 6 t + 11 t^2 + 6 t^3.
```
Betti numbers: `b_0 = 1, b_1 = 6, b_2 = 11, b_3 = 6`, all higher zero.
Euler characteristic `χ(F(R^2, 4)) = 1 − 6 + 11 − 6 = 0`.

### d = 3

**[thm]** (Fadell–Neuwirth, Cohen). For `d ≥ 3`, `F(R^d, n)` is simply connected.
Its cohomology is the Orlik–Solomon-type algebra generated by classes
`ω_{ij} ∈ H^{d−1}(F(R^d,n))`, `1 ≤ i < j ≤ n`, with relations
```
ω_{ij} ∧ ω_{jk} + ω_{jk} ∧ ω_{ki} + ω_{ki} ∧ ω_{ij} = 0   (Arnold/Cohen).
```
For `d = 3`, `n = 4`: nontrivial cohomology only in degrees that are multiples of
`d−1 = 2`. The Poincaré polynomial is
```
P_{F(R^3, 4)}(t) = ∏_{k=1}^{3}(1 + k t^2) = 1 + 6 t^2 + 11 t^4 + 6 t^6.
```
So `b_0=1, b_2=6, b_4=11, b_6=6`, others zero. `χ = 1+6+11+6 = 24` (all even degrees).

These are the **Coulomb baseline** Betti numbers for the unordered question; the
unordered (symmetric) quotients are recovered in §5.

## 3. The Weber critical-radius stratum

For a like-sign pair `(i,j)` with reduced mass `μ_{ij}`, the **critical radius**
`ρ_{ij} = q_i q_j / (μ_{ij} c^2)` is where the effective radial mass changes
sign; inside `ρ`, like charges attract (a Riemannian → Lorentzian metric flip;
see `theory/Regularization.md`).

In the 2+/2− problem the like pairs are exactly `(1,2)` and `(3,4)`, giving
**two** critical hypersurfaces in `F(R^d, 4)`:
```
Σ_+ := { r_{12} = ρ_{12} },     Σ_− := { r_{34} = ρ_{34} }.
```
Each is smooth codim-1 (level set with non-vanishing gradient), diffeomorphic to
`S^{d−1} ×` (a base in remaining coordinates). Their intersection has codim 2
and is generically transverse, yielding a stratified space
`F(R^d,4) ⊃ Σ_+ ∪ Σ_− ⊃ Σ_+ ∩ Σ_−`. The four unlike pairs contribute *no*
critical sphere.

The **sub-Weber region** `W_{−−} := {r_{12} < ρ_{12}, r_{34} < ρ_{34}}` is open;
each pair-coordinate slice is contractible (an open `B^d × B^d` of dimer
relative positions), and the nontriviality lives in the inter-dimer fiber.

## 4. Cohomology of the supercritical complement

Each `Σ_±` is a closed cooriented codim-1 submanifold (level set of `r_{ij}` with
non-vanishing gradient); a tubular neighborhood `N(Σ_±)` retracts onto `Σ_±` and
`N(Σ_±)\Σ_±` is a trivial `R^×`-bundle (the super/sub-critical sides).

**[thm]** (Thom / Alexander–Lefschetz). The long exact sequence of the pair
`(M, M\Σ)` for a closed cooriented codim-1 submanifold gives, after Thom shift,
one new linking class in `H^{d−1}(M\Σ)` per connected component of `Σ`.

**[conj 4.1]** The Weber-critical complement satisfies
```
H^*(F(R^d,4) \ (Σ_+ ∪ Σ_−))  ≅  H^*(F(R^d,4))  ⊕  Z^2
```
with the two extra classes in degree `d−1`, one linking class per critical sphere.

**Justification.** Each `Σ_±` is connected (a sphere bundle over a contractible
inter-dimer base) and globally cooriented by `dr_{ij}`. In `d = 3`, Alexander
duality `H̃^i(R^n\K) ≅ H̃_{n−i−1}(K)` applied to each `Σ_±` (which contains an
`S^2` factor — the dimer's critical relative sphere) yields one class in
`H^2`. Two surfaces ⇒ `Z^2`. The `d = 2` case is identical with `S^1` in place
of `S^2`. The hedge is in transferring `R^n` to `F(R^d,4)`; `Σ_±` is disjoint
from `Δ`, so the splitting is clean.

Per-slice, the sub-Weber region `W_{−−}` is contractible; its global homotopy
type reduces to the inter-dimer base `F(R^d,2) ≃ S^{d−1}`.

## 5. Symmetry reduction (handoff to Agent 2)

The discrete group `G := S_{12} × S_{34}` (swap the two positives, swap the two
negatives) acts freely on `F(R^d, 4)`. The quotient
```
F(R^d, 4) / G
```
has Euler characteristic `χ / |G| = χ(F)/4` whenever the action is free, which
holds away from `Δ`. From §2:
```
d = 2:  χ(F(R^2,4)/G) = 0/4 = 0.
d = 3:  χ(F(R^3,4)/G) = 24/4 = 6.
```
After further reducing by translations, rotations and time we land on the
manifold-with-corners parameterized (in slice form) by the radial dimer
coordinates `(r_+, r_−) ∈ R_{≥0}^2` and the inter-dimer geometry. The two
"corner walls" `r_+ = 0` and `r_− = 0` are exactly the like-pair collision
strata in the reduced space. The Weber critical strata become two interior
hypersurfaces `r_+ = ρ_+`, `r_− = ρ_−` parallel to the walls.

## 6. Frauenfelder–Weber 2024 as a covering-space obstruction

**[thm]** (Frauenfelder–Weber 2024, Thm 2.1). For a like-charge pair below the
critical radius with nonzero angular momentum `ℓ`, the trajectory reaches
`r = 0` in finite physical time with infinite winding number; no smooth
coordinate-time transformation removes the singularity.

**Topological reformulation.** Let `L_ε` be the link of the central collision
inside a small neighborhood of `r_{12} = 0` (a punctured radial 2-disk × angular
`S^1`). Trajectories with `ℓ ≠ 0` lift to the universal cover of `L_ε ≃ S^1`,
where the Weber radial equation is single-valued. The lift of an inspiraling
orbit exits every compact set in finite time — its monodromy under one physical
revolution has **infinite order**. Equivalently, the orbit defines an element of
`π_1(L_ε) ≅ Z` of unbounded multiplicity in finite time.

**[conj 6.1]** (Topological obstruction to bound sub-critical orbits.) Any
trajectory of the 2+/2− Weber system that enters the open sub-critical
neighborhood `W_+ := {r_{12} < ρ_{12}}` of the like-positive pair with non-zero
relative angular momentum `ℓ_{12} ≠ 0` cannot be part of a `C^1` periodic orbit
of the full 4-body system. Reason: the period would have to be a multiple of
the (infinite) winding monodromy of the link of the central collision, which is
impossible.

This is the Agent-3 conceptual payload for the final report: **the only smooth
periodic orbits of the 2+/2− Weber system can either avoid `W_±` entirely, or
enter it head-on (`ℓ_{ij} = 0`) where the `C^0` collision-bounce of
`theory/Regularization.md` applies.** Generic sub-critical bound dynamics is
ruled out by a topological — not a dynamical — argument.
